# Security Policy

## Supported version

Security fixes are applied to the latest revision of the default branch. This
educational repository is not a production service.

## Reporting

Please use GitHub’s private vulnerability reporting feature rather than a public
issue. Include the affected file, impact, a minimal reproduction, and a safe
fix if known. Never include API keys, customer data, or active exploit secrets.

If a credential is exposed, revoke it immediately in the relevant provider
console before reporting the code issue.
